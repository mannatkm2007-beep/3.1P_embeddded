# Task 3.1P – Trigger and Notification Based on Sensor Data

This project develops an embedded system using an Arduino Nano 33 IoT and BH1750 light sensor to monitor sunlight exposure for a terrarium. The BH1750 measures light intensity in lux using I2C communication, while the Arduino connects to Wi-Fi and compares the measured light level with a defined threshold of 1000 lux. When the light level reaches or exceeds the threshold, the Arduino sends a `sunlight_detected` event to an IFTTT Webhook, which generates an email notification. When the light level falls below the threshold after sunlight has been detected, the Arduino sends a `sunlight_stopped` event and IFTTT sends another email notification. The system was tested by shining a phone flashlight on the sensor and then removing it to verify both trigger conditions and corresponding email notifications. The project demonstrates how sensor data, Wi-Fi communication, IFTTT Webhooks and automated notifications can be combined to create a simple real-world monitoring system.
